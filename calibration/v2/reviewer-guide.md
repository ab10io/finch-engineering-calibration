# Calibration v2 reviewer guide

The answer key was frozen before model inference. Review demonstrated repository evidence, not project size or prose volume. Static review cannot establish build success, passing tests, runtime correctness, deployment, performance, security certification, or runtime accessibility.

Track alignment is separate from the core score. Missing Open Source licensing prevents that track from being demonstrated but does not erase unrelated engineering evidence. Each required citation path maps to a frozen evidence contract or retained weak control. Failed calibration results remain versioned and are never repaired by moving the answer key after scoring.
