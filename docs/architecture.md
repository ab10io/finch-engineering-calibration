# Architecture and data flow

## Boundary

A normalized disruption feed becomes an ordered instruction model. The UI exposes semantic landmarks, live-region priority, keyboard navigation, text scaling, and saved offline routes. Visual maps are supplementary, never the only representation.

## Data flow

Signed feed -> schema validation -> instruction ordering -> offline cache -> semantic route view -> optional map.

## Operational limitation

Indoor positioning, real-time crowding, runtime screen-reader interoperability, and user-study outcomes are not verified.
