# Finch Engineering Calibration

This public repository contains deliberately synthetic, non-secret projects used to calibrate Finch's Core Engineering Evidence Score. Nothing here is participant work, production software, or evidence of a real person or team.

Each `fixture/*` branch is an independent root commit containing exactly one synthetic project. The `main` branch contains only calibration metadata, expected-outcome ranges, structured submission answers, prompts, and reports. Finch assessments pin an exact commit SHA and never execute fixture code.

All fixtures are excluded from leaderboards. Secret-shaped strings and prompt-like instructions are inert adversarial test data, not live credentials or instructions.
