# Review Assistant

> Synthetic calibration fixture — not participant work or production software.

A bounded assistant that helps benefits caseworkers locate supporting policy passages while preserving human decisions and uncertainty.

## Intended users

Public-benefit caseworkers reviewing complex eligibility documents with accountable human sign-off.

## Purpose

Reduce search time without allowing a model to approve, deny, or silently rewrite a case decision.

## Evidence boundary

Finch may inspect this frozen repository statically. It must not install packages, execute tests, start the project, or infer runtime behavior.

## Known limitation

Only the frozen policy corpus is searchable; multilingual quality and real workflow latency remain unverified.
