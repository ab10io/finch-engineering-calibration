# Transit Guide

> Synthetic calibration fixture — not participant work or production software.

An offline route-instruction interface designed with blind and low-vision riders for disrupted public transit.

## Intended users

Blind and low-vision riders navigating temporary platform, elevator, and route changes with unreliable connectivity.

## Purpose

Provide concise, screen-reader-first disruption instructions without depending on visual maps or continuous connectivity.

## Evidence boundary

Finch may inspect this frozen repository statically. It must not install packages, execute tests, start the project, or infer runtime behavior.

## Known limitation

Indoor positioning, real-time crowding, runtime screen-reader interoperability, and user-study outcomes are not verified.
