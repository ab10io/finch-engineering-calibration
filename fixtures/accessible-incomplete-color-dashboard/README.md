# Color Access Dashboard

> Synthetic calibration fixture — not participant work or production software.

A dashboard that adds a high-contrast color palette toggle.

## Intended users

Dashboard users who prefer higher contrast.

## Purpose

Offer an alternate set of chart colors.

## Evidence boundary

Finch may inspect this frozen repository statically. It must not install packages, execute tests, start the project, or infer runtime behavior.

## Known limitation

Canvas charts have no text alternative, controls are pointer-only, and mobile reflow is unknown.
